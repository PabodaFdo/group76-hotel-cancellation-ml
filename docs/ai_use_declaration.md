# AI Use Declaration — Group 76

## 1. Overview

Generative AI tools, including OpenAI ChatGPT, were used as supplementary resources during the IT3091 Machine Learning project, *Hotel Booking Demand — Cancellation Risk Prediction*.

AI assistance supported technical clarification, troubleshooting, and documentation while project decisions were assessed against the dataset, experimental results, and assignment requirements.

## 2. Areas of AI Assistance

- **Conceptual Support:** Clarification of machine learning concepts, preprocessing techniques, and evaluation methods.
- **Technical Guidance:** Assistance with Python code, debugging, and understanding model configurations.
- **Result Interpretation:** Support in interpreting evaluation metrics and experimental findings.
- **Documentation:** Assistance with organizing and refining technical explanations and project documentation.

## 3. Verification and Responsibility

Machine learning experiments were executed and evaluated using the project's datasets and notebooks. Model performance, preprocessing decisions, and final recommendations were assessed using the recorded results.

AI-generated suggestions were reviewed for relevance and correctness before inclusion in the project.

## 4. Declaration

AI was used as a supporting learning and development resource. Responsibility for the submitted implementation, experimental findings, technical decisions, and academic integrity remains with Group 76.
