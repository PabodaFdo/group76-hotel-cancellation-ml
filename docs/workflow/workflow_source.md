# Project Workflow

Current intended high-level flow:

Business Problem
→ Data Understanding
→ EDA
→ Data Quality Review
→ Leakage Review
→ Preprocessing
→ Feature Engineering
→ Train / Validation / Test Strategy
→ Baseline Model
→ Alternative Models
→ Evaluation
→ Model Comparison
→ Final Model Selection
→ Interpretation
→ Business Recommendation
→ Limitations and Responsible AI

> The workflow may be refined after group review.
